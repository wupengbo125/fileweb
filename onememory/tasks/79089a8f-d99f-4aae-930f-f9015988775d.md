# 支持网页预览

## 背景诉求
用户在手机上打开 FileWeb 查看 HTML 文件时，默认只在编辑器中显示源代码（原文），希望能够直接以网页形式展示。

## 关键改动
1. **app.py**:
   - 增加 `mimetypes` 与 `unquote` 导入
   - 增加 `/raw/` 路由与 `api_raw` 处理，按文件后缀返回真实 MIME 类型（如 `text/html; charset=utf-8`）
2. **index.html**:
   - 在 `#editor` 顶部导航栏增加「预览/源码」切换按钮 `#previewBtn`
   - 增加 `#preview` iframe 容器，点击预览时若有未保存改动自动保存并以 iframe 加载 `/raw/<path>`
   - 刷新时若处于预览模式直接刷新 iframe
